Metacognitive Learning System
Constraint → Self-Appraisal → Regulation → Adaptation

This interactive research object translates a qualitative study of socially distanced online learning into a dynamic model of learner self-appraisal. It shows how metacognitive knowledge, academic self-concept, formal assessment, affect, self-regulation and transformative awareness interact within a constrained digital learning environment.

SYSTEM STATE

Effective learner profile

This state emphasizes structured planning, active monitoring, strategic resource use and the use of learning experience as feedback for future adjustment.

SELECTED COMPONENT

Online constraint

Socially distanced online learning changes the conditions under which learners must organize attention, motivation, time, communication and self-monitoring.

Learner discourse points to the home environment as both a resource and a source of difficulty.

THEMATIC DISTRIBUTION
VR-assisted thematic analysis

The study used immersive VR as a collaborative analysis space, allowing researchers to work with shared documents, projected transcripts and avatar-based interaction during later stages of thematic coding.
